# ParAnnoying Messenger Audit & Improvements in `ChatKit-Compose`

During design of **ChatKit-Compose**, we audited the real-world legacy `stfalcon-studio/ChatKit` integration inside `ParAnnoying` (`offline` module) to remove every workaround required by XML `MessagesList`, `DialogsList`, `MessageInput`, and `UserInfoActivity`.

## Resolved Workarounds & Pain Points

| `ParAnnoying` File / Pattern | Legacy Workaround Required | Native Solution in `ChatKit-Compose` |
| :--- | :--- | :--- |
| `ChatAdapter.kt` + 8 `*Viewholder.kt` classes + `MessageContentChecker.kt` | Needed 8 separate `Incoming*` / `Outgoing*` `ViewHolder` classes, reflection instantiation, XML layout files, `Byte` type IDs, and an untyped `ChatViewHolderPayload`. | Unified strongly-typed `MessageContentType` sub-interfaces (`Image`, `Gif`, `Video`, `Voice`, `Poll`, `Location`, `Contact`, `Document`, `SystemEvent`) plus `CustomContentConfig.Builder` Compose lambdas. |
| `ChatOverviewAdapter.kt` (`companion object { var instance }`) | Stored a static `instance` reference so inner `DialogViewHolder` could reach `Context` and `SecurityInterfaceHolder` without constructor injection crashes. | Stateless `@Composable` rows capture dependencies directly in Kotlin scope—zero static singletons or reflection. |
| `ChatAdapterHelper.kt` (`startInfiniteRotation`) | Attached a manual `ObjectAnimator` + `LiveData.observeForever` listener on `IconicsTextView` plus an `OnAttachStateChangeListener` to avoid leaking `SENDING` spinners. | `MessageStatus.SENDING` animates automatically via `rememberInfiniteTransition` inside Compose's composition lifecycle and respects `ChatKitAnimationConfig.animateStatusRotation`. |
| `ChatAdapter.kt` (`setStatus`) & `AbstractMessage.kt` | Manually built iconics glyph strings for unconfirmed (`?`), warning (`!`), confirmed (`✓`), and `NEW` status labels. | `MessageStatus` includes `UNCONFIRMED`, `WARNING`, `SENDING`, `SENT`, `DELIVERED`, `READ`, `FAILED`, plus `IMessage.statusLabel`. |
| `ChatActivity.kt:701` (`registerViewClickListener(R.id.messageText)`) | Registered a click listener on `R.id.messageText` to reveal hidden/starred messages because registering on `R.id.bubble` blocked RecyclerView selection. | Native `IMessage.isMasked` (and `ChatKitFeatureConfig.maskMessagesByDefault`) renders a tap-to-reveal shield inside the bubble while preserving long-press multi-selection on the row. |
| `ChatActivity.kt:172-193` (`TextWatcher` + `messageCountTextView`) | Attached a custom `TextWatcher` on `input.inputEditText` to calculate split message count when crossing `MAX_MESSAGE_SIZE`. | `ChatKitFeatureConfig(maxMessageChunkSize = ...)` enables the chunk counter pill directly inside `MessageInput`. |
| `FileMessage.kt` (`getExtension`, `numberOfFiles`, `isFileAvailable`, `fileSizeText`) | Classified extensions (`.jpg.txt`, `.opus`, `.mp4`, `.vcf`, `.geojson`, `.poll`) and handled missing files / `+N files` overlays inside custom `FileMessage` and `ChatAdapterHelper`. | Extracted into `ChatFileTypeDetector`, `DocumentMessage`, `VideoMessage`, and `ChatMessage` (`isAvailable`, `additionalFilesCount`, `fileSizeText`). |
| `ChatActivity.kt:601` (`getMessagePosition`) & `DialogsList` jump | Filtered `adapter.items` manually to skip `Date` wrapper items when computing adapter positions to scroll to search results. | Built directly into `MessagesListState.getMessageTimelineIndex(messageId)`, `scrollToMessageId(messageId)`, and `requestScrollToMessage(messageId)`. |
| `ChatAdapterHelper.kt:59-83` (`setUserImage` & `"MAYBE: "` prefix) | Manually toggled `avatar.visibility`, checked `OfflineGroup` `"MAYBE: "` prefix, and attached click listeners to launch `UserInfoActivity`. | `MessagesList` supports `authorNameFormatter: ((M) -> String)?` and `onAvatarClick: ((IUser) -> Unit)?` directly. |
| `UserInfoActivity.kt` + `UserProfileItem.kt` + `UserProfileAdapter.kt` | Built a dedicated RecyclerView + `UserProfileAdapter` just to render hero avatar, static metadata, security issues, group members, and action rows. | Provided as a reusable, Material 3 **`ChatProfileSection`** composable (`ChatProfileItem.SectionHeader`, `StaticInfo`, `Action`, `MemberRow`, and `ChatProfileQuickAction`). |
