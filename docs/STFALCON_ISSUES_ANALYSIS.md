# Curated `stfalcon-studio/ChatKit` GitHub Issues & How ChatKit-Compose Solves Them

We audited the historical issue tracker of [`stfalcon-studio/ChatKit`](https://github.com/stfalcon-studio/ChatKit/issues) (254 fetched issues) and filtered out legacy build/Bintray/JCenter/AndroidX migration noise to focus on **18 high-value feature requests and architectural bugs**.

| Status | Issue | Legacy Title | How `ChatKit-Compose` Addresses It |
| :---: | :---: | :--- | :--- |
| ✅ | [#116](https://github.com/stfalcon-studio/ChatKit/issues/116) | *I manage to add Location, Video to this chatKit* | Built-in `MessageContentType.Location` (stylized map card + coordinates) and `MessageContentType.Video` (thumbnail, play button, duration, file size, `+N files` badge). |
| ✅ | [#246](https://github.com/stfalcon-studio/ChatKit/issues/246) | *Adding more than one type (voice,files,locations,...etc)* | First-class interfaces & composables for `Image`, `Gif`, `Video`, `Voice`, `Poll`, `Location`, `Contact`, `Document`, and `SystemEvent` — plus `CustomContentConfig.Builder` for unlimited custom types. |
| ✅ | [#182](https://github.com/stfalcon-studio/ChatKit/issues/182) | *How can I do whatsapp like replies?* | Native `IMessage.replyTo` support renders quoted reply strips inside bubbles and a dismissible `ReplyingToBanner` inside `MessageInput`. |
| ✅ | [#223](https://github.com/stfalcon-studio/ChatKit/issues/223) | *Is there anyway to add typing view to the message list?* | `MessagesList(typingUsers = ...)` renders an animated three-dot `TypingIndicatorBubble` obeying `ChatKitAnimationConfig`, alongside `MessageInput(onTypingChanged = ...)`. |
| ✅ | [#218](https://github.com/stfalcon-studio/ChatKit/issues/218) | *Is it possible to have more than 2 participants in a conversation?* | `IDialog.users: List<IUser>` automatically detects group threads (`users.size > 2`), prefixes sender names in `DialogsList`, and enables author headers + member avatars in `MessagesList`. |
| ✅ | [#231](https://github.com/stfalcon-studio/ChatKit/issues/231) | *Support only one avatar in the last messages in group sequence messages from same user.* | `buildTimelineItems` assigns `MessageGroupPosition` (`SINGLE`, `FIRST`, `MIDDLE`, `LAST`) and renders avatars strictly on `SINGLE`/`LAST` bubbles. |
| ✅ | [#129](https://github.com/stfalcon-studio/ChatKit/issues/129) | *Group messages for same user* | Consecutive messages from the same author within 5 minutes on the same day automatically merge corner radii (`bubbleCornerRadius` vs `groupedCornerRadius`). |
| ✅ | [#160](https://github.com/stfalcon-studio/ChatKit/issues/160) | *Message with author name* | Supported via `MessagesListStyle(showIncomingAuthorName = true)` (shown on `FIRST`/`SINGLE` of a group) and customizable via `authorNameFormatter`. |
| ✅ | [#180](https://github.com/stfalcon-studio/ChatKit/issues/180) | *Send data from custom MessageHolder to MessageActivity.* | Eliminated ViewHolder isolation: `CustomContentConfig` lambdas run in the caller's Compose scope and pass direct callbacks (`onPollVote`, `onLocationClick`, `onContactClick`, `onDocumentClick`, `onMediaClick`, `onAvatarClick`). |
| ✅ | [#312](https://github.com/stfalcon-studio/ChatKit/issues/312) | *Custom ViewHolder not working with Kotlin* | Zero reflection or XML `ViewHolder` instantiation; strongly-typed Kotlin reified `registerType<MyMessage> { ... }` DSL. |
| ✅ | [#308](https://github.com/stfalcon-studio/ChatKit/issues/308) | *automatic scroll when updating a listitem in the MessagesList* | Compose `SnapshotStateList` + keyed `LazyColumn` updates only the changed item in place without jumping scroll position. |
| ✅ | [#171](https://github.com/stfalcon-studio/ChatKit/issues/171) | *Calling adapters update method scrolls the recyclerview up slightly* | Solved by Compose snapshot diffing + stable `key = { it.key }` items in `MessagesList` (`reverseLayout = true`). |
| ✅ | [#211](https://github.com/stfalcon-studio/ChatKit/issues/211) | *Get Message Position?* | Added `MessagesListState.getMessageTimelineIndex(messageId)` (accounting for injected date headers) and `scrollToMessageId(messageId)` / `requestScrollToMessage(messageId)`. |
| ✅ | [#264](https://github.com/stfalcon-studio/ChatKit/issues/264) | *Load More View to (footer of Dialog List ,Header of Message List)* | Built-in `MessagesList(isLoadingMore = true, onLoadMore = ...)` renders a clean loading indicator at the historical top of `MessagesList`. |
| ✅ | [#284](https://github.com/stfalcon-studio/ChatKit/issues/284) | *Set tick(for message seen) to text message* | Built-in `MessageStatus` (`SENDING`, `SENT`, `DELIVERED`, `READ`, `UNCONFIRMED`, `WARNING`, `FAILED`) renders read ticks, clock rotation, and status labels automatically. |
| ✅ | [#179](https://github.com/stfalcon-studio/ChatKit/issues/179) | *Message Long Click Context Menu possible?* | Full `onMessageClick`, `onMessageLongClick`, and `onSelectionChanged` multi-selection support that works harmoniously even alongside tap-to-reveal masked messages. |
| ✅ | [#255](https://github.com/stfalcon-studio/ChatKit/issues/255) | *Select device's local photo or take picture with camera in MessageInput default button* | Added `rememberChatAttachmentLaunchers` (`ActivityResultContracts.PickMultipleVisualMedia` + `OpenMultipleDocuments`) and an expandable `AttachmentPickerTray` in `MessageInput`. |
| ✅ | [#202](https://github.com/stfalcon-studio/ChatKit/issues/202) & [#123](https://github.com/stfalcon-studio/ChatKit/issues/123) | *Avatars sometimes have a black background* / *Path too large to be rendered into a texture* | Replaced `ShapeImageView` bitmap-shader masking with Compose `Modifier.clip(CircleShape)` + `ChatAvatar` deterministic Material color initials fallback. |
| ✅ | [#103](https://github.com/stfalcon-studio/ChatKit/issues/103) & [#121](https://github.com/stfalcon-studio/ChatKit/issues/121) | *Recyclerview scrolls down when soft keyboard appears* / *Emoji* | Works seamlessly with edge-to-edge `Modifier.imePadding()` and `navigationBarsPadding()` in `MessageInput`, plus built-in emoji `IMessage.reactions` pills. |
